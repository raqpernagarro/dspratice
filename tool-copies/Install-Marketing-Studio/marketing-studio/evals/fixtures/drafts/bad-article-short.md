# What an agent needs from your design system

Designers now ask agents to build components, and the agents answer with confidence. The components look right, and they ship.

The problem is what the agent had to guess along the way. A colour sits one step off the palette. A radius appears that exists nowhere in the system.

## Context before code

An agent fills every gap with a guess. A palette, a spacing scale and a short list of the rules your product follows give it fewer gaps to fill.

## A check that fits the work

Take the last component an agent built. Compare it with the system, not only with the ticket, and write down every decision that nobody made.
