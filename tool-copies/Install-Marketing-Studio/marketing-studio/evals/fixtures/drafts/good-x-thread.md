An agent reads only what you wrote down.

It cannot ask the colleague who sat next to the designer last spring.

---

Every rule your team follows by habit is invisible to it.

So it fills the gap with a confident guess.

---

A guess that looks right is the hardest kind to catch in review.

The component passes and the product still drifts.

---

The fix sits upstream: write the rules behind the components in a form an agent can read.

Tokens, states, and when to use what and why.

---

Start with the rules your team never wrote down.

List what a new colleague would have to ask about, then write it into the system.
