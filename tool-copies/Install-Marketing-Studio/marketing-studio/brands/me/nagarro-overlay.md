# Nagarro overlay

Rules added on top of `voice.md` and `content-rules.md` when a piece has `mode: nagarro`, that is, when it promotes your employer's offering, article, event or team. If you never write company-aligned posts, leave this file as it is and use `mode: personal`.

## When this applies

A piece is company-aligned when it promotes an offering, article, event or team, or when it belongs to a campaign with `mode: nagarro`. You still write as yourself; this file decides what may be named and claimed. In `personal` pieces the company may be mentioned as a fact but never promoted. In a campaign with `neutral: true`, it is never mentioned at all.
