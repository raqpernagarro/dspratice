# Iconography and marks

## Brand icons

126 line icons from the Figma "Scribble icons" set (node 3396-35706): a 96×96 viewBox, uniform stroke, rounded caps, drawn in `currentColor`. Use `NagarroSlides.icon("name")`; the **Icon** card lists every name. Examples: `api`, `cloud`, `database`, `goal`, `growth`, `handshake`, `idea`, `security`, `team`.

- Colour: inherit `fg-100`; `accent-primary` (mint) for the single accent on a dark slide.
- Size: set on the wrapper. 48–96px on cards, 24–32px next to text.
- Templates with an `icon` field take one of these names.

## Caring icons

Assets › Caring: one icon per value (agile, caring, client-centric, global, intelligent, non-hierarchical, responsible) in three treatments:

- **Badge**: a filled circle in the value's colour with a white glyph (572×572).
- **Icon**: the glyph in petrol-black and mint.
- **Icon transparent**: a mint glyph on no background, for any ground.

Use one treatment per slide, and only for values content. The two **Caring logo** files (Light and Mint Green) sign off a culture or values chapter.

## Scribbles

Assets › Scribbles: nine hand-drawn mint strokes (underlines, circles, arrows, emphasis marks). **Scribble 5** is a full 1920×1080 background flourish. Use one scribble moment per slide at most: underline a key word, circle a number, or sweep behind a cover title. They add warmth; they are not structure.

## App icon

Assets › Logos › `app-icon-circle.svg`, `app-icon-square.svg`: the compact brand mark (88×88) for tiles and avatars.

## Don't

- Emoji, clip-art, stock icon sets or filled icon styles next to these line icons.
- Icons as bullet points on every line of a list.
- Recolouring caring badges outside their value colour.
