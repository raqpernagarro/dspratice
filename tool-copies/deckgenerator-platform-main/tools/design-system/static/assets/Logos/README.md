# Logos

The official Nagarro lockups, copied verbatim from the brand SVGs (1024×768 canvas, logo centred).

- **Horizontal**, **Vertical**, **Vertical Small**, **Tagline Horizontal**, **Tagline Vertical**, **Tagline Vertical Small**.
- Colourways: **Light** (petrol-black wordmark, mint mark: for light grounds), **Dark** (white wordmark, mint mark: for dark grounds), **Petrol Black**, **White** and **Green** (single ink).
- `nagarro-logo.svg` is the wordmark in `currentColor` (shows black in an `<img>`); `nagarro-logo-black.svg` and `nagarro-logo-white.svg` are fixed-ink versions.
- `app-icon-circle.svg`, `app-icon-square.svg`: the compact 88×88 brand mark.

On slides, don't place a lockup: the Header renders the logo. Use these for documents, covers outside the slide system and exports. Never redraw, stretch, recolour or add effects.
