# Caring

The seven Nagarro caring values (agile, caring, client-centric, global, intelligent, non-hierarchical, responsible), each in three treatments:

- `badge-*`: a filled circle in the value's own colour (see *Brand and principles*) with a white glyph, 572×572.
- `icon-*`: the glyph in petrol-black and mint, 512×512.
- `icon-*-transparent`: a mint (`accent-primary`, #47d7ac) glyph on no background, for any ground.

Plus the **Caring logo** in Light and Mint Green (1024×768) to sign off a values chapter. Use one treatment per slide, and only for content about the values.
