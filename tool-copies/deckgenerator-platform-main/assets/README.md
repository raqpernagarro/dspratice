# Brand assets

Official Nagarro brand assets. The SVGs are the authoritative source for the brand
palette — see `../Design.md` for the confirmed tokens extracted from them.

## Logos
- `logo/` — in-app wordmark: `nagarro-logo.svg` (`currentColor`, theme-aware, used
  by the deck chrome), plus fixed `-black` / `-white` variants.
- `logos/` — official lockups. Axes: **Horizontal / Vertical / Tagline / …Small**
  × color **Dark, Light, White, Green, Petrol Black**. (`(1)` = duplicate export.)
- `caring-logo/` — the "Caring" signature logo: `Light`, `Mint Green` (1024×768).

## Icons & marks
- `caring-icons/` — the 7 Nagarro values, each in three treatments:
  **Badge** (572×572, color-filled) · **Icon** (512×512) · **Icon … transparent**
  (512×512, mint glyph). Values: agile, caring, client-centric, global,
  intelligent, non-hierarchical, responsible.
- `app-icon/` — compact app marks `Circle.svg`, `Square.svg` (88×88).

## Decoration
- `scribbles/` — 9 hand-drawn mint-green marks. Sizes vary; **Scribble 5** is a
  full-slide 1920×1080 background flourish.

## Photography
- `photography/` — 209 brand photos (~2048px; 173 landscape, 36 portrait).
  Authentic workplace/people imagery. Landscape → full-bleed & split layouts;
  portrait → side-by-side text/image.
