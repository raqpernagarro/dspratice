## Not part of Base UI

Breadcrumb is built on the same tokens and spec system as the Base UI components, as a `<nav>` with an ordered list: there is no Base UI part for it.

```tsx
<Breadcrumb.Root>
  <Breadcrumb.Item href="/">Home</Breadcrumb.Item>
  <Breadcrumb.Item href="/projects">Projects</Breadcrumb.Item>
  <Breadcrumb.Item current>Design system</Breadcrumb.Item>
</Breadcrumb.Root>
```
