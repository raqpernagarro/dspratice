## Not part of Base UI

Pagination is built from the system’s own Button and Icon Button, on the same tokens and spec system as the Base UI components: there is no Base UI part for it.

```tsx
const [page, setPage] = useState(1)
<Pagination pageCount={20} page={page} onPageChange={setPage} />
```
