## Key constraints

- Library is consumed via `npm link` — no published package
- AppShell main area has built-in padding — never add a wrapper inside it
- Icons come from `lucide-react` — list it at the same version `ds-ngr` uses
- Token alias chain must always be preserved: primitives → semantics → component tokens
- Sentence case everywhere — labels, headings, actions

Full rules in the [Consumer guide](?path=/docs/guidelines-consumer-guide--docs).
