This page provides a visual overview of the core design tokens that power DS-Ngr. These values are automatically synchronized from Figma via Style Dictionary.

Our color system is built on a semantic layer that resolves to primitive values. This ensures consistency across themes and provides clear intent for every color role.

## 🔡 Typography

We use `var(--font-family-default)` across all components. Hierarchy is established through the font scale and weight tokens.

### Font Scale

Pick a row by eye, then use the `font/size/*` and `var(--font-size-*)` / `var(--font-line-height-*)` values below each preview in your component styles.

<div
  style={{
    display: 'flex',
    flexDirection: 'column',
    border: '1px solid var(--color-border-neutral-primary)',
    borderRadius: 'var(--shape-radius-sm)',
    overflow: 'hidden',
    marginTop: '1rem',
  }}
>
  {[
    'micro',
    'label',
    'body-sm',
    'body-md',
    'display-sm',
    'display-md',
    'display-lg',
    'display-xl',
    'display-2xl',
    'display-3xl',
  ].map((name, index, all) => (
    <div
      key={name}
      style={{
        display: 'flex',
        flexDirection: 'column',
        alignItems: 'stretch',
        gap: 'var(--space-xs)',
        padding: 'var(--space-md)',
        borderBottom:
          index < all.length - 1 ? '1px solid var(--color-border-neutral-primary)' : undefined,
      }}
    >
      <p
        style={{
          margin: 0,
          width: '100%',
          overflow: 'hidden',
          textOverflow: 'ellipsis',
          whiteSpace: 'nowrap',
          color: 'var(--color-foreground-neutral-primary)',
          fontFamily: 'var(--font-family-default)',
          fontSize: `var(--font-size-${name})`,
          lineHeight: `var(--font-line-height-${name})`,
          fontWeight: 'var(--font-weight-regular)',
        }}
      >
        The quick brown fox jumps over the lazy dog
      </p>
      <div
        style={{
          fontFamily: 'monospace',
          fontSize: 'var(--font-size-micro)',
          lineHeight: 'var(--font-line-height-micro)',
          color: 'var(--color-foreground-neutral-secondary)',
        }}
      >
        <div style={{ marginBottom: 'var(--space-2xs)' }}>font/size/{name}</div>
        <div>var(--font-size-{name})</div>
        <div>var(--font-line-height-{name})</div>
      </div>
    </div>
  ))}
</div>

## 📏 Spacing & Layout

Spacing tokens are used to create rhythm and relationship between elements.

### Space
One scale for padding, margin, and gap — `--space-{none|3xs|2xs|xs|sm|md|lg|xl|2xl|3xl}`.

<div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
  {[
    { name: '3xs', val: 'var(--space-3xs)' },
    { name: '2xs', val: 'var(--space-2xs)' },
    { name: 'xs', val: 'var(--space-xs)' },
    { name: 'sm', val: 'var(--space-sm)' },
    { name: 'md', val: 'var(--space-md)' },
    { name: 'lg', val: 'var(--space-lg)' },
    { name: 'xl', val: 'var(--space-xl)' },
    { name: '2xl', val: 'var(--space-2xl)' },
    { name: '3xl', val: 'var(--space-3xl)' }
  ].map(s => (
    <div key={s.name} style={{ display: 'flex', alignItems: 'center', gap: '1.5rem' }}>
      <div style={{ width: s.val, height: '24px', background: 'var(--color-background-accent-strong-default)', borderRadius: '2px' }} />
      <span style={{ fontSize: '0.8rem', fontFamily: 'monospace', color: 'var(--color-foreground-neutral-secondary)' }}>--space-{s.name}</span>
    </div>
  ))}
</div>

### Padding
Padding uses the same `--space-*` scale (there is no separate inset scale).

<div style={{ display: 'flex', gap: '1.5rem', flexWrap: 'wrap' }}>
  {[
    { name: '3xs', val: 'var(--space-3xs)' },
    { name: '2xs', val: 'var(--space-2xs)' },
    { name: 'xs', val: 'var(--space-xs)' },
    { name: 'md', val: 'var(--space-md)' },
    { name: 'lg', val: 'var(--space-lg)' }
  ].map(s => (
    <div key={s.name} style={{ 
      padding: s.val, 
      background: 'var(--color-background-neutral-secondary)',
      border: '1px solid var(--color-border-neutral-primary)',
      borderRadius: 'var(--shape-radius-md)',
      display: 'inline-block'
    }}>
      <div style={{ width: '40px', height: '40px', background: 'var(--color-background-accent-strong-default)', opacity: 0.15, border: '1px dashed var(--color-background-accent-strong-default)' }} />
      <div style={{ fontSize: '0.7rem', marginTop: '6px', textAlign: 'center', color: 'var(--color-foreground-neutral-secondary)' }}>--space-{s.name}</div>
    </div>
  ))}
</div>

## 📐 Radius (shape tier)

Defines the rounding of corners for consistent component shape. Tokens use the `--shape-radius-*` prefix (`shape` tier — split from `size` because radius is an independently themeable dial).

<div style={{ display: 'flex', gap: '2.5rem', alignItems: 'flex-start', flexWrap: 'wrap' }}>
  {[
    { name: 'none', val: 'var(--shape-radius-none)' },
    { name: 'small', val: 'var(--shape-radius-sm)' },
    { name: 'medium', val: 'var(--shape-radius-md)' },
    { name: 'large', val: 'var(--shape-radius-lg)' },
    { name: 'xlarge', val: 'var(--shape-radius-xl)' },
    { name: 'full', val: 'var(--shape-radius-full)' }
  ].map(r => (
    <div key={r.name} style={{ textAlign: 'center' }}>
      <div style={{ 
        width: '100px', 
        height: '100px', 
        background: 'var(--color-background-neutral-secondary)', 
        border: '2px solid var(--color-background-accent-strong-default)', 
        borderRadius: r.val 
      }} />
      <div style={{ fontSize: '0.8rem', marginTop: '8px', color: 'var(--color-foreground-neutral-primary)', fontWeight: 'bold' }}>{r.name}</div>
      <div style={{ fontSize: '0.7rem', color: 'var(--color-foreground-neutral-secondary)' }}>{r.val}</div>
    </div>
  ))}
</div>

## Elevation (effect tier)

Elevation communicates Z-axis hierarchy through `box-shadow`. Tokens use the `--color-shadow-elevation-*` prefix (`effect` tier — shadow color is separate from the spatial `size` tokens that define offset, blur, and spread).

<ThemeToggle>

<div
  style={{
    display: 'flex',
    gap: 'var(--space-lg)',
    alignItems: 'flex-start',
    flexWrap: 'wrap',
    padding: 'var(--space-xl)',
    background: 'var(--color-background-neutral-secondary)',
    borderRadius: 'var(--shape-radius-sm)',
    overflow: 'visible',
  }}
>
  {[
    {
      name: 'sm',
      figma: 'color/shadow/elevation/sm',
      token: 'var(--color-shadow-elevation-sm)',
      use: 'Cards, chips',
      shadow:
        '0 var(--primitive-size-1) var(--effect-blur-sm) var(--primitive-size-negative-1) var(--color-shadow-elevation-sm)',
    },
    {
      name: 'md',
      figma: 'color/shadow/elevation/md',
      token: 'var(--color-shadow-elevation-md)',
      use: 'Dropdowns, tooltips',
      shadow:
        '0 var(--primitive-size-4) var(--effect-blur-md) var(--primitive-size-negative-2) var(--color-shadow-elevation-md)',
    },
    {
      name: 'lg',
      figma: 'color/shadow/elevation/lg',

      </div>
      <div style={{ fontSize: '0.7rem', marginTop: '6px', color: 'var(--color-foreground-neutral-tertiary)' }}>{tier.use}</div>

  ))}
