# Writing in the hub

One voice: an experienced colleague helping someone finish a task. Clear, natural English; professional, approachable and confident.

## Rules of thumb

- Lead with what the person can do or will get, not with how the tool works.
- Use familiar words. Explain a necessary term once, then use it the same way everywhere.
- Short sentences. One idea per sentence.
- Say what an action needs, what it produces and what comes next ("You need · You get · Then").
- No slogans, no exaggeration, no forced friendliness, no narrating the implementation.
- Name the limit once, where it matters. The full list lives in **Settings › About this tool**.
- Never present sample figures as measured results. Never invent savings, ROI, timelines, credentials or integration coverage.

## Terms

| Term | Meaning | Use |
|---|---|---|
| Client demo | The guided showcase we present in meetings | Not "client workspace", "client experience" or "portal" |
| Project | One client's or prospect's design-system work | Not "engagement" in navigation |
| Client request | An RFP, questionnaire or brief we respond to | The list is called Opportunities |
| System contract | One small file in the client's repository that records tokens, components, rules and which side leads for each part, so people and tools read the same thing | Explain it the first time on a page |
| Finding | A place where the system breaks one of its rules, with evidence and the side to fix | |
| Figma change | The Figma side of a fix, reviewed in Figma before it is applied | Not "change set" in headings |
| Files AI tools read | What we generate from the contract for each AI tool | Not "channels" in headings |
| Preparation / client demo version / demo | Draft / published version / demo session | "Update the client demo" publishes |
| Backed by a source · Our recommendation · Assumption · Open question | The four kinds of statement in a draft | A matching passage is evidence to check, not an answer |

## Verbs on buttons

| Verb | Means |
|---|---|
| **Preview** | Look, without changing anything |
| **Save** | Keep your preparation (most fields save as you type, and say so) |
| **Download** | A file is saved by this browser |
| **Update the client demo** | Publish a new version that the client demo shows |
| **Present client demo** | Open the demo as presenter; **Back to preparation** returns |
| **Show me** | Perform a demo chapter's action |
| **Simulated** (label) | Looks live, but nothing reaches GitHub, Figma or a model |
